# Independent referee check of CLAIM.md (v1) — Oct 27 2026

Fresh agent, told to try to refute the claim, with its own code (review/agent/) and without reading the author's code.

**Verdict: claim holds, with presentation fixes. No fatal or mathematical error found.**

## What was checked
1. F1–F3 by direct computation:
   - F1 for primes p < 2000.
   - F2 on 20k random pairs.
   - F3 on all 900×900 type pairs.
2. Sharpness example on integers up to 20000, including a = b. A second extremal set was found: {43, 57 (mod 100)}. These two are the only cross-class residue pairs mod 100 that work.
3. Worst-case-b argument:
   - The q | b case gives Δ = (Z′−X′)/q² ≤ 0, or −X′/q².
   - The coincidence case (ℓ² | b²+1) raises Z_ℓ from 1−3/ℓ² to 1−2/ℓ².
   - Exact CRT-period counts on the prime sets {7,13}, {7,13,17}, {11,13,17} and {7,11,13} matched the product formula, with the maximum equal to the worst case.
4. Uniformity in b: the error is ≤ N/T + π(N) for P_b (twice that for D), so the ε–T–N₀ argument goes through. No missing case was found in f(s,S).
5. Constants, from partial products to 5·10⁷ with rigorous tails:
   - K₁ = 0.0273465
   - K₂′ = 0.0501139 = 1 − 9.375/π²
   - J′ = 0.0142450
   - Q = 0.963123
   - Generic b (no coincidences): 0.00128.
6. Optimization, by two methods other than CBC:
   - exhaustive enumeration over the 64 Galois-closed sets (439 valid pairs, each evaluated on all 900 types);
   - HiGHS MILP with cuts.

   Results:
   - Maximum is exactly 18/900, with exactly two maximizers.
   - Second best is all 900 types, at 0.017115.
   - Everything reduces to 72K₂′ + 828J′ < 18. This holds for any J′ < 0.01738; K₁ in place of J′ fails (0.0292).
7. Exact max-clique computations:
   - For all N ≤ 10000, the overall maximum equals the 7 mod 25 count.
   - For N from 557 to 10000, the best non-pure set is the 7/93 or 43/57 mod 100 set (one larger for some N ≤ 556).
   - The best set containing a type outside C is about 0.0155N at N = 4000–10000.
8. Empirical densities for a ≤ 10⁷:
   - b values tested: 1, 30030, 9699690, 9999991, 99, 3141 and 33459226 (0 to 3 coincidences).
   - All matched the exact per-b predictions (|z| ≤ 0.4).
   - The largest D∧P_b density observed was 0.01120, below J′.
